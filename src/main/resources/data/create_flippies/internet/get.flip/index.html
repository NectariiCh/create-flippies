This modem's network serves operating systems for the netinstall floppy, listed in index.txt, and the world's shared folder at localfilesys.com.

Operating systems and software come in content packs (*.flippack) that the server owner installs in config/create_flippies/packs/ or in the world's flippies_packs/ folder, then loads with /flippies packs reload. If index.txt lists nothing, no OS pack is installed: ask the server owner.
